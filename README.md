# Gokul AI Bot

Personal AI portfolio and assistant built with Next.js, TypeScript, Supabase and Vercel.

## Vision
A personal website that works as both a portfolio and an AI-powered assistant.

## Planned features
- Personal portfolio
- AI assistant chat
- Projects and skills
- Notes and tasks
- Supabase-backed data
- Responsive mobile-first UI
- Vercel deployment

## Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase
- Vercel
