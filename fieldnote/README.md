# FieldNote v1.0.0

FieldNote is the first Daily App: a lightweight offline-first Android app for capturing crop and field observations.

## v1.0.0
- Crop + field tagging
- Quick observation notes
- Local offline persistence
- Search observations
- Swipe/delete notes
- Mobile-first Material 3 UI

## Build
```bash
flutter pub get
flutter create --platforms=android .
flutter build apk --release
```

APK output: `build/app/outputs/flutter-apk/app-release.apk`
