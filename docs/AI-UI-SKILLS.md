# AI UI Skills

This project uses two UI/UX resources:

- UI/UX Pro Max: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- 21st.dev Magic Chat: https://21st.dev/magic-chat

Install UI/UX Pro Max locally with:

```bash
npx ui-ux-pro-max-cli init --ai universal
```

Magic Chat is a UI component and should be integrated into the Next.js chat interface after installing its project dependencies/component files.
