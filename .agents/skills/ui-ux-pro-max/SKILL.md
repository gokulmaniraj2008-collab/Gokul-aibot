# UI/UX Pro Max

Project UI/UX guidance skill for Gokul-aibot.

Use the official UI/UX Pro Max project for the full skill, references, design intelligence, and CLI assets:
https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

Official local installation:

```bash
npx ui-ux-pro-max-cli init --ai universal
```

When designing or modifying the app, prioritize responsive mobile-first layouts, accessible interactions, clear hierarchy, consistent spacing/typography, and production-ready UI.
